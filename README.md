# C 语言报错翻译器 · 网页版

把 **Dev-C++ / GCC 的英文报错**原文粘进去 → 告诉你**哪一行、什么错、怎么改**。

纯前端、**不联网、不上传代码、不登录**。

**在线用**：<https://xiaogaokunkun.github.io/c-error-helper-web/>

## 它解决什么

刚开始学 C 的人，大部分时间不是卡在写不出代码，是卡在**看不懂报错**：报错是英文、是术语、报的位置还常常不是真正出错的地方。

这个网页就是为这件事写的——**学长视角，不是教授视角**。它不跟你说「语法错误」，它说「上一行末尾是不是忘了加分号 `;`」。

## 四个标签页

| 标签页 | 干什么 |
|---|---|
| **报错翻译** | 粘报错原文 → 中文解释 + 改法。一次报多条时，还会给你一份「**先改哪个**」的顺序清单 |
| **代码体检** | 粘整个 `.c` 文件 → 揪出中文全角标点（**精确到第几行第几列**）、括号不配对、经典写法坑 |
| **逻辑坑** | 8 条「编译能过、结果却错」的坑（`if (n=5)`、整数除法、`scanf` 漏 `&`……） |
| **定积分** | 数值解一个定积分，用来**核对**高数作业（卷面上该写的步骤还是得写） |

共 **36 条编译报错规则 + 8 条逻辑坑**。

## 怎么用

- **在线**：点上面的地址。
- **离线**：下载整个文件夹，双击 `index.html` 就能用。
- **单文件版**（想直接发给别人）：跑一次 `python build.py`，把 4 个文件内联成一个
  `dist/c-error-helper-单文件版.html`，那一个文件双击就能用。

## 自动翻译：URL 参数

页面支持把报错直接拼进网址，打开就自动翻译：

```
index.html?t=<base64(报错原文)>&c=<base64(源码，可选)>
```

`b64uDec` 标准 base64 和 base64url 两种都认。

> 直接双击打开（`file://`）也能用，但「读剪贴板」按钮在 `file://` 下可能被浏览器拦——用在线地址更稳。

## 和 VS Code 插件的关系

这是我**最早做的那一版**。因为 Dev-C++ 里没法悬停看解释，只能把报错复制出来、粘进网页查；用了一阵嫌麻烦，才想明白该把它塞进编辑器里——于是有了 VS Code 扩展：

**`xiaogaokunkun/c-error-helper`** —— 扩展市场搜 `c-error-helper`（显示名「C语言报错翻译器」）。

## 源码结构

```
index.html    骨架（引下面三个）
style.css     样式
rules.js      规则库（36 条编译报错 + 8 条逻辑坑）——改规则只动这里
app.js        逻辑（解析 / 渲染 / 代码体检 / 定积分 / URL 参数）
build.py      把上面 4 个内联成单文件版 → dist/c-error-helper-单文件版.html
```

拆开是为了好维护；给别人的时候用 `build.py` 产出的单文件版就行。
